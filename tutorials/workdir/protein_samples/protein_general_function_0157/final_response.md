## Functional summary

This 768-aa protein is identified as **coatomer subunit γ-2 (COPG2)**, matching the reviewed *Oryza sativa* japonica reference UniProt Q6Z382 at **100% identity across the full query sequence**. The reference coverage is 86.4%, so the aligned reference is shorter than the query.

COPG2 is a component of the **COPI vesicle coatomer**. The coatomer associates with Golgi-derived, non-clathrin-coated vesicles and supports vesicle budding and protein transport through the Golgi; it is especially important for **retrograde transport from Golgi to ER**, including retrieval of proteins bearing dilysine motifs. The sequence analysis identifies an **Adaptin_N domain (residues 28–541)** and a **COP-gamma_platf domain (residues 624–768)**, consistent with this coatomer-subunit assignment.
