## Functional identification

The 436-residue protein is **ribosomal RNA small-subunit methyltransferase B**, commonly called **RsmB** (also related to RsmF nomenclature in some annotations).

### Main function

It specifically methylates **cytosine 967 of bacterial 16S rRNA**, producing **5-methylcytidine (m⁵C967)**:

\[
\text{16S rRNA-C967} + \text{SAM}
\rightarrow
\text{16S rRNA-m⁵C967} + \text{SAH}
\]

- **EC:** 2.1.1.176  
- **Rhea:** RHEA:42748  
- **Substrate:** 16S rRNA  
- **Methyl donor:** S-adenosyl-L-methionine (SAM)  
- **Localization:** Cytoplasm  
- **Molecular role:** rRNA modification and likely contribution to proper ribosome function

## Evidence strength

This assignment is **high confidence**:

- The sequence is an **exact 100% identity match** to reviewed UniProt protein **Q8PG22**.
- It is 86.7% identical to another reviewed RsmB protein and 64.3% identical to a further homolog.
- The sequence contains the expected methyltransferase-related domain architecture:
  - **NusB-like domain:** residues 12–133
  - **RsmF-B ferredoxin-like domain:** residues 145–217
  - **RsmB-F methyltransferase domain:** residues 241–432

The reference protein contains a conserved catalytic nucleophile near **position 377**, consistent with the C5-cytosine methyltransferase mechanism.

## Concise summary

This is a **soluble bacterial 16S rRNA cytosine-C5 methyltransferase, RsmB**, responsible for installing **m⁵C967** in the small-subunit rRNA using **SAM**.
