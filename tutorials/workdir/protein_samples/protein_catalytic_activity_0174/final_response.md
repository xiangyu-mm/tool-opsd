## Functional assignment

The protein is **fructose-bisphosphate aldolase**, specifically the zinc-dependent class II enzyme (**EC 4.1.2.13**).

The sequence is **288 amino acids** long and is an exact sequence match to reviewed UniProt entry **P75089**. It also contains the characteristic **F_bP_aldolase domain** (Pfam **PF01116**, residues 3–287).

## Catalyzed reaction

\[
\text{Dihydroxyacetone phosphate (DHAP)}
+
\text{Glyceraldehyde-3-phosphate (G3P)}
\rightleftharpoons
\text{Fructose-1,6-bisphosphate (FBP)}
\]

The enzyme catalyzes:

- **Aldol condensation in gluconeogenesis:** DHAP + G3P → FBP
- **Aldol cleavage in glycolysis:** FBP → DHAP + G3P

This reaction is also recorded as **Rhea RHEA:14729**.

## Additional features

- **Cofactor:** binds **two Zn²⁺ ions per subunit**
  - one catalytic zinc ion
  - one structural zinc ion
- **Oligomeric state:** annotated as a **homodimer**
- **Localization:** cytosolic
- **Functional confidence:** very high, based on an exact reviewed-sequence match and full-length domain agreement.
