## Functional assessment

This 532-amino-acid protein is strongly supported as **CTP synthase** (EC **6.3.4.2**), an enzyme in de novo pyrimidine/CTP biosynthesis. The assignment is based on near-full-length similarity to reviewed archaeal CTP synthases—up to **76.8% identity at 99.8% query coverage**—and matches to the **CTP_synth_N** and **GATase** domains.

CTP synthase catalyzes the ATP-dependent amination of UTP. With glutamine as the nitrogen donor, the overall reaction is:

**UTP + L-glutamine + ATP + H₂O → CTP + L-glutamate + ADP + phosphate + 2 H⁺**

It can also use ammonia directly:

**UTP + NH₄⁺ + ATP → CTP + ADP + phosphate + 2 H⁺**

Thus, this is a **CTP-producing ligase**, not a dehydrogenase or oxidoreductase. Homologs are annotated as homotetramers, but that oligomeric state is not independently established for this query protein.
