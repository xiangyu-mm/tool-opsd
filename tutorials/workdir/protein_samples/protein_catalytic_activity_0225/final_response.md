## Functional identification

The 438-aa protein is most consistent with **RlmN**, a **dual-specificity radical-SAM RNA methyltransferase** (**EC 2.1.1.192**).

This assignment is strongly supported by curated homologs showing:

- **61.7–65.4% sequence identity**
- **83–87% query coverage**
- E-values of approximately **10⁻¹⁵⁹ to 10⁻¹⁶⁹**
- A cysteine-rich radical-SAM iron–sulfur binding region

## Catalytic activity

RlmN methylates the **exocyclic N2 atom of adenine** in RNA:

1. **23S rRNA adenine 2503 → N2-methyladenosine 2503**
2. **tRNA adenine 37 → N2-methyladenosine 37**

The simplified reaction is:

\[
\text{RNA-adenosine} + \text{SAM}
\rightarrow
\text{RNA-N}^{2}\text{-methyladenosine}
\]

Mechanistically, RlmN is an unusual **radical-SAM enzyme** that uses a second SAM molecule to generate the 5′-deoxyadenosyl radical. A more complete reaction representation is:

\[
\text{RNA-adenosine}
+ 2\,\text{SAM}
+ \text{reducing equivalents}
\rightarrow
\text{RNA-N}^{2}\text{-methyladenosine}
+ \text{5′-deoxyadenosine}
+ \text{S-adenosylhomocysteine}
+ \text{methionine}
\]

The enzyme binds one **[4Fe–4S] cluster**, coordinated by cysteine residues, and is expected to function in the cytoplasm.

**Conclusion:** This sequence encodes an **RlmN-type [4Fe–4S]/SAM-dependent RNA adenine N2 methyltransferase**, acting on both 23S rRNA A2503 and tRNA A37.
